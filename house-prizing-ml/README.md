# House Price Prediction AI

A machine learning application that predicts house prices based on property features.

## Technologies 
  
  -python
  -Pandas
  -Numpy
  -Scikit-learn
  -Matplotlib
  -Streamlit
  -Git & Github

## Project Goals

  1. Explore and preprocess housing data.
  2. Train  machine learning models.
  3. Evaluate Prediction accuracy.
  4. Build an interactive application online.
  5. Deploy the application online.
